# 🎰 Slot Machine

Proyecto correspondiente al **Primer Ciclo** de la asignatura **Programación Orientada a Objetos** de la **Escuela Colombiana de Ingeniería Julio Garavito**.

![Slot Machine](https://i.pinimg.com/1200x/e6/9e/72/e69e72e9927ae5f4f3f044570a677c05.jpg)

*Imagen de referencia tomada de Pinterest.*

---

## 📖 Descripción

Este proyecto implementa un simulador de máquina tragamonedas (*Slot Machine*) inspirado en el **Problem I** de la Maratón Internacional de Programación.

El desarrollo fue realizado utilizando los principios de **Programación Orientada a Objetos**, permitiendo administrar ruedas, símbolos y configuraciones visibles de una máquina tragamonedas.

---

## ⚙️ Funcionalidades

El simulador permite:

- Crear una máquina tragamonedas.
- Agregar y eliminar ruedas.
- Agregar y eliminar símbolos.
- Girar una rueda específica.
- Girar todas las ruedas.
- Consultar símbolos visibles.
- Consultar la configuración actual.
- Contar símbolos visibles distintos.
- Verificar estados de jackpot.
- Mostrar y ocultar la representación gráfica de la máquina.
- Finalizar la ejecución del simulador.
